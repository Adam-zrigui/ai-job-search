## About the role

MixRank processes petabytes of data every month from web crawling. Customers include Google, Amazon, Facebook, Intel and Adobe across sales, marketing, finance and security. The company is profitable, employee-owned and has no dependence on outside funding. Applicants from all geographies and backgrounds are welcome.

The codebase is written in Python, Rust, SQL, JavaScript/TypeScript and Nix. Core technologies for productivity are Python, PostgreSQL, Linux and Git. The company cares more about the candidate as a person than specific technology experience.

The team operates two datacenters, a distributed file system, full-scale web crawls and static analysis of Android and iOS apps. The role offers difficult technical problems with room to grow.

## Who they want

Generalist software engineers for web applications, data mining, machine learning and data science, ETL, data modeling, database scaling, infrastructure and DevOps. The role can be catered to the subset that matches the engineer's interests.

Beneficial experience includes PostgreSQL, Python, Rust, Linux, TypeScript, Nix, frontend and backend web development, and data mining.

Applicants should include an updated resume. No degree requirement and no US visa requirement are listed.
