 Type: Independent Contractor Schedule: Flex-Time (15-25 hours / week) Education: Bachelor Degree in Computer Science, or a similar field, or equivalent experience

 Experience: 3+ Years

 Location: Remote


 Motu Novu seeks to retain the services of a motivated Front-End Developer to work with React to build modern, responsive user interfaces for custom applications built with back-end PHP and Symfony.


 What You Do 
 
 
 Develop and maintain React-based user interfaces.

 Collaborate with senior developers on full-stack features.

 Write clean, maintainable code following team standards.

 Participate in code reviews and learn from feedback.

 Assist with API integration and basic back-end tasks.

 Debug and fix front-end issues.

 
 
 What You Need: Technical 
 
- Solid knowledge of PHP and familiarity with object-oriented programming.

- Solid understanding of React fundamentals (components, hooks, router v7, state management validation React 19).

- Proficiency in TypeScript and modern JavaScript (ES6+).

- Experience with responsive design and CSS-in-JS (Emotion).

- Basic understanding of RESTful APIs design principles and API integration using Axios.

- Familiarity with version control (Git) and containerized development.

- Basic knowledge of Vite build tool and development workflow.

- Willingness to learn Symfony framework and its components.

 
 What You Need: Non-Technical 
 
- Confident and poised attitude in internal and external interactions.

- Ability to work in a distributed, collaborative, asynchronous environment.

- Ability to maintain the highest level of confidentiality.

- Exceptional written and oral communications skills in (American) English.

- Bona-fide setup as an independent contractor.

 
 What You Get 
 
- Base Compensation: $35-$50/hour, depending on qualifications and experience.

- Benefits: Fully flexible schedule, discretionary yearly performance bonus (up to 25% of base yearly compensation).

- Growth Opportunities: collaborate on the design, development, and maintenance of wide range of applications for a variety of clients and use cases; learn about new technologies, frameworks, and languages; optionally, occasional travel within Europe and/or to the USA;

- Relocation: If interested, opportunity to relocate to Cody, Wyoming, USA, with visa sponsorship if necessary and feasible, after at least 3 years of successful collaboration.
